# VIPER RUSSIA

Стартовый исходный проект Android-лаунчера VIPER RUSSIA. Интерфейс — на русском языке.

## Сборка APK через GitHub
1. Загрузите содержимое архива в корень репозитория `svet-ai/viper-russia`.
2. Откройте вкладку **Actions**.
3. Выберите workflow **Сборка VIPER RUSSIA APK**.
4. Нажмите **Run workflow** или отправьте новый commit.
5. После успешной сборки скачайте artifact **VIPER-RUSSIA-APK**.

## Параметры
- Имя: VIPER RUSSIA
- Application ID: `com.viper.russia`
- Версия: `1.0.0`
- Сервер: `94.23.168.153:3123`
- Минимальная версия Android: 6.0 (API 23)

## Важно о текущей готовности
В проекте есть рабочая стартовая оболочка лаунчера на русском языке и workflow сборки APK.
Функции загрузки ZIP-кэша, распаковки, SHA-256-манифеста, живого статуса сервера, аккаунтов, новостей из backend и админ-панели пока не реализованы — для них нужны проверенные URL/формат манифеста и серверный API.
Кнопка «Играть» не имитирует подключение: для неё нужен совместимый Android-клиент GTA San Andreas Multiplayer и его точный способ запуска.
